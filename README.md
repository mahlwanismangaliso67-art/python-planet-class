🪐 Planet Class – Python OOP Project

📌 About the Project

This project is a beginner Python Object-Oriented Programming (OOP) exercise focused on creating a "Planet" class and working with instances, methods, and data validation.

The class represents planets using their name, planet type, and the star they orbit. It also validates the supplied arguments and provides readable output for each planet object.

🚀 Features

- Planet class: Defines the structure of a planet object.
- Instance creation: Creates three planet instances: Earth, Jupiter, and Neptune.
- Type validation: Raises a "TypeError" if the name, planet type, or star is not a string.
- Value validation: Raises a "ValueError" if any of the arguments is an empty string.
- Orbit method: Uses "orbit()" to return a message describing the planet's orbit.
- String representation: Uses "__str__()" to display each planet's information in a readable format.

🛠️ Technologies Used

- Python 3
- Object-Oriented Programming (OOP)
